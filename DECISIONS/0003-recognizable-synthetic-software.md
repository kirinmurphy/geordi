# Decision 0003: Recognizable synthetic software

## Status

Accepted on July 26, 2026.

## Context

The contextual-atlas revision improved orientation, but fictional application
names still required the product owner to learn invented products before
learning HAL. Familiar software offers an existing mental model for processes,
files, package management, startup behavior, and performance.

## Decision

- Shape the default fictional Mac around Docker Desktop, Visual Studio Code,
  cmux, ChatGPT, Brave Browser, Homebrew, Oh My Zsh, and TypeScript installed
  with npm.
- Keep every version, size, process observation, resource sample, event, and
  ownership conclusion deterministic and synthetic.
- Do not scan the real Mac during Phase 0.
- Distinguish applications from package managers, shell frameworks, and
  packages in the domain and presentation.
- Base high-level structural relationships on official product documentation
  where available while avoiding claims about the user's actual installations.

## Consequences

Users can apply knowledge they already have while evaluating HAL's navigation
and explanations. The fixture is illustrative, not an inventory or diagnostic
report of the development machine.
